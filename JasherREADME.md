# Vital Signs Backend API

A RESTful backend system for managing patient vital signs with an admin approval workflow. Built with Python, and PostgreSQL.

## Features

- ✅ Complete CRUD operations for vital signs
- ✅ Admin approval workflow (submissions held until reviewed)
- ✅ JWT authentication and role-based access control
- ✅ Input validation and data sanitization
- ✅ PostgreSQL database with constraints
- ✅ Admin dashboard endpoints

## Technology Stack

- **Runtime:** Python
- **Framework:** Python
- **Database:** PostgreSQL
- **Authentication:** JWT with bcrypt
- **Validation:** express-validator

## System Requirements

- Python (Version 3.13)
- PostgreSQL (v14 or higher)
- python-pip package manager

## Development Environment

This project was **developed and tested on Arch Linux**. The code is platform-independent and should work on Windows, macOS, and other Linux distributions with minor setup differences.
